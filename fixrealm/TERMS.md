# TERMS — определения предмета

Протокол QWR предметно-нейтрален. Здесь живут определения конкретного исследования.
Каждый термин: название, определение одной фразой, источник или карточка, дата.
Предметный словарь кодов %s пополняется в блоке DICT ниже; инструмент dict load разрешает %s отсюда.
В протокол qwr/bot предметная математика не вшивается.

## Термины dry-run (пример оформления, мета-утверждения о механике протокола)

- Замок — файл захвата роли или задачи, создаваемый атомарно без sha.
- Сдвиг — положительный результат этапа по списку mod/tang.txt.
- Потолок — предел стоимости этапа: 10^7 операций или 120 секунд.

## Термины предмета "арифметические тождества" (посев IDE, A0105)

- Равенство — отношение эквивалентности, замещающее термины; в школьной арифметике 1+1=2 есть теорема (PM: 54.37), в формальных системах определяется аксиомами.
- Аксиоматика — набор утверждений, принимаемых без доказательства; смена аксиоматики меняет истинность тождеств (булевы алгебры, Z2).
- Область чисел — множество, в котором интерпретируются символы: N, Z, Q, R, C; знак "+" перегружается по области.
- Конгруэнция — отношение a ~ b mod m, сохраняющее сложение; продолжение тождества через смену знака отношения.

## Термины линии A0106-A0108 (посев IDE 2026-11-26T03:20Z)

- Семейство sum=k·prod — уравнения a₁+…+aₙ = k·a₁…aₙ в натуральных; при n=2 даёт критерий k|2 (A0106).
- Спуск по последней переменной — метод %s4: фиксировать n−1 переменных, последняя определяется делимостью; доказывает конечность перебора без полного куба.
- Египетское разложение — сумма unit-дробей %s5; гипотеза 4/n (A0108) связана с семейством sum=k·prod заменой eᵢ=1/(kaᵢ).
