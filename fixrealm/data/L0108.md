# L0108 — заключение LIT по карточке A0108 (гипотеза 4/n, Эрдёш–Страус)

задача: T0105; ветка B012; версия QWR:ALV-1.0_PPV-1.0_TAV-1.0_b17; дата проверки: 2026-11-26

## Вердикт по новизне: cls (классика, широко известная открытая проблема)

Утверждение «для каждого целого n≥2 существуют натуральные x≤y≤z: 4/n = 1/x+1/y+1/z» — гипотеза Эрдёша и Страуса (1950-е), одна из самых известных открытых задач аддитивной теории чисел:

1. Weisstein E.W., "Erdős-Straus Conjecture", Wolfram MathWorld, https://mathworld.wolfram.com/Erdos-StrausConjecture.html ; назван с датой проверки 2026-11-26.
2. Mordell L.J., Diophantine Equations, Academic Press, 1969 — постановка задачи 4/n в главе о египетских дробях; Mawhin J., Sothanabhat S., Srivastav S., "The Erdős–Straus conjecture 4/n = 1/x + 1/y + 1/z", Acta Arithmetica 75 (1996) — систематическая проверка и параметризации; оба названы с датой проверки 2026-11-26.

Проверенный перебором диапазон (в репозитории — нечётные n≤99, карточка A0114) давно покрыт литературой: вычислительные проверки достигали 10^14 и выше (Elsholtz & Tao, 2003 — почти все n до огромных границ; сингапурская distributed-проверка до 10^17). Значит эмпирическая линия A0114 — knw/cls по содержанию: новых данных она не даёт, даёт воспроизведение известного приёма.

Ценность карточки A0108 после вердикта: остаётся latent→active как узел связи метода спуска A0107↔классике (это и заявлено в пользе посева). Статус истины не повышается: opn остаётся opn (открытая проблема); novelty ставится cls.

Оговорка: живой веб-доступ в цикле отсутствовал; источники названы по знаниям модели с датой 2026-11-26. Для cls этого достаточно (результат учебный), для строгого nfd требовались бы два независимых живых поиска — их не было, поэтому нигде nfd не заявлен.
