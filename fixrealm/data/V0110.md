## Утверждение
Для натуральных a<=b<=c и целого k>=1 уравнение a+b+c = k·a·b·c имеет решения ровно: {(1,2,3)} при k=1, {(1,1,2)} при k=2, {(1,1,1)} при k=3; пусто при k>=4. С точностью до перестановки это полный список.

## Письменное доказательство
1. Граница первой переменной. Из упорядоченности и равенства: 3c >= a+b+c = k·a·b·c => k·a·b <= 3. Значит при k>=4 решений нет вовсе (k·a·b >= 4 противоречит). Это закрывает ветку пустоты k>=4 полностью, без перебора.
2. При фиксированных (a,b) третья переменная единственна: c = (a+b)/(k·a·b − 1), знаменатель положителен (иначе сумма неотрицательна против положительной). Условие c>=b даёт (a+b) >= b(kab−1), то есть a+b >= kab²−b; при kab>=3 левая линейна по b, правая квадратична — ветвь конечна и обрывается.
3. Перебор сокращённой области (пункт 1 ограничивает её конечным числом случаев):
   - k=1: ab<=3 => (a,b) ∈ {(1,1),(1,2),(1,3)}. c=(a+b)/(ab−1): (1,1)→знаменатель 0; (1,2)→c=3 ⇒ (1,2,3); (1,3)→c=2 < b — тот же кортеж с точностью до перестановки. Итог: одно семейство {(1,2,3)}.
   - k=2: 2ab<=3 => только (1,1). c=2/1=2 ⇒ {(1,1,2)}.
   - k=3: 3ab<=3 => только (1,1). c=2/2=1 ⇒ {(1,1,1)}.
4. Единственность: на каждом шаге спуска c определяется формулой однозначно, а пункт 3 исчерпывает все допустимые (a,b). Разные семейства дают разные значения ka·(произведение), значит не пересекаются. ∎

## Независимая сверка (воспроизводимость + усиленные сетки)
- Рецепт автора (спуск B=60, brute B=80) воспроизведён побуквенно: множества совпали для k=1..6.
- Полный brute-force n=3, k=1..6, B=120 (сильнее авторского): расхождений нет.
- Доказательная сетка a,b<=5000 с точным выводом c: найдено ровно по одному решению при k=1,2,3, ноль при k=4..6 (~1e7 проверок делимости, 10.7 с, под потолком).
- Сокращённая доказательная область (пункты 1–2) с полными границами: идентичный результат за <0.01 с.
