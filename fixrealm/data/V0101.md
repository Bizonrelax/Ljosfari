# V0101 — Проверка A0101: письменное доказательство эквивалентности

карточка: fixrealm/cards/A0101.md
вердикт: подтверждено, emp -> prf на основании письменного доказательства ниже; новизна остаётся unc (поиск источников не выполнялся)
метод: независимый алгебраический разбор булевых формул из bin/qwr.py (lock_live, fresh_trace, cmd_release --stale), сверка с артефактом data/A0101-table.tsv другим прогоном сетки
версия: QWR:ALV-1.0_PPV-1.0_TAV-1.0_b8

## Утверждение
Для любых неотрицательных вещественных возраста замка a и возраста следа t замок снят как брошенный тогда и только тогда, когда a > 60 и t > 60.

## Доказательство
По коду qwr.py: live(a,t) = (a <= 60) OR (fresh(t)), где fresh(t) = (t <= 60) (срез cutoff=60.0, age_min<=cutoff). Снятие разрешено ровно когда NOT live(a,t). По закону де Моргана: NOT ((a<=60) OR (t<=60)) = (a>60) AND (t>60). Это в точности формулировка A0101. Обе импликации получены из одного тождества, контрпримеров на всей области определения нет. Пороги строгие, равенство 60 даёт живость — что отдельно зафиксировано в A0102.

## Независимая сверка
Повторный прогон сетки {30,61,90,180} x {15,59,60,61,120} дал 20/20 согласованных ячеек против arтефакта WRK; расхождений нет. Замечание: арифметика real-valued покрыта тождеством де Моргана, дискретная сетка — только контроль реализации.

## Основание смены статуса
emp -> prf по правилу emp->prf: письменное доказательство плюс закрытая задача проверки этим агентом (CHK другой роли относительно WRK-владельца этапа). Новизна не повышена: knw/nfd требуют источников, поиск не выполнялся.
