# V0115 — Проверка A0101: письменное доказательство подтверждено, emp -> prf

карточка: fixrealm/cards/A0101.md
задача: T0101 (PLN блок A0101-A0104, исполнитель WRK qwen-agent; проверка CHK Bizonrelax — другой агент)
предыдущее заключение: fixrealm/data/V0101.md (этап CHK прерван до фиксации; перепроверено заново, не зачтено автоматически)
вердикт: ПОДТВЕРЖДЕНО. emp -> prf. Новизна остаётся unc (поиск источников не выполнялся).
метод: независимый алгебраический разбор реализации + тройная числовая сверка под потолком (ops ~2e5, <1 с, память <16 МБ)
версия: QWR:ALV-1.0_PPV-1.0_TAV-1.0_b17

## Утверждение (пересказ карточки)
Замок снят как брошенный тогда и только тогда, когда возраст замка a > 60 минут И возраст следа владельца t > 60 минут.

## Проверка реализации (код, а не таблица)
bin/qwr.py: lock_live(m) = age_min(born_at) <= 60 OR fresh_trace(owner), fresh = t <= 60 (cutoff=60.0);
cmd_release --stale отказывает (403), если a <= 60 ИЛИ t <= 60; снимает (200+stale_release в inbox) иначе.
Снятие разрешено ровно когда NOT live(a,t). По де Моргану: NOT((a<=60) OR (t<=60)) = (a>60) AND (t>60) —
в точности формулировка A0101. Тождество покрывает все неотрицательные вещественные a, t; обе импликации
следуют из одной эквивалентности, контрпримеров на всей области определения нет. Пороги строгие: равенство
60 даёт живость — согласуется с клетками trace=60/age=60 в артефакте.

## Числовая сверка (независимые прогоны от автора)
1. Артефакт WRK fixrealm/data/A0101-table.tsv: 20 строк перечитаны, каждая пересчитана против кодовой модели — 0 расхождений.
2. Усиленная сетка {0,30,59.999,60,60.001,61,90,180,1e6} x {0,15,59.999,60,60.001,61,120,1e6}: 72 клетки — 0 расхождений (граница с обеих сторон, включая ε=0.001).
3. Случайные вещественные a,t ∈ [0,1e4): 200 000 пар (seed=1) — 0 расхождений.
Воспроизводимость рецепта автора подтверждена на расширенном диапазоне (это и есть сдвиг этапа: emp-эмпирика 20 клеток усилена до тождества + 2e5 случайных точек без расхождений).

## Основание смены статуса
emp -> prf по G7: письменное доказательство (это заключение, алгебраическое, для всех вещественных) плюс закрытая задача проверки T0101, выполненная другим агентом (CHK Bizonrelax ≠ автор WRK qwen-agent). Статус не завышен дальше prf: ref требует явного контрпримера (отсутствует), knw/nfd требуют источников (поиск не выполнялся) — новизна unc.

## Рецепт воспроизведения
live(a,t)=a<=60 or t<=60; red(a,t)=a>60 and t>60; проверить NOT live == red на сетках выше и 2e5 случайных пар seed=1; артефакт fixrealm/data/A0101-table.tsv; версия QWR:ALV-1.0_PPV-1.0_TAV-1.0_b17.
