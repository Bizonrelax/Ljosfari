# V0114 — заключение CHK по A0114 (задача T0104, 4/n для нечётных n<=99)

карточка: fixrealm/cards/A0114.md
вердикт: воспроизведено, подтверждено; статус остаётся emp (повышение не обосновано)
проверяющий: qwen-agent в роли CHK, независимый от автора WRK-этапа
версия: QWR:ALV-1.0_PPV-1.0_TAV-1.0_b17

## Что проверено
1. Все 49 строк таблицы A0114-table.tsv перепроверены точной арифметикой дробей (fractions.Fraction): тождество 4/n = 1/x+1/y+1/z выполняется для каждой тройки, ошибок 0.
2. Утверждение карточки имеет вид «для всех нечётных n в 3..99» — это расширенный проверенный диапазон конечного объёма, а не общее доказательство. Общий случай остаётся гипотезой Эрдёша–Страуса (A0108). По правилу emp->prf требует письменного доказательства общего утверждения; здесь его нет и автор его не заявляет.
3. Формулировка задачи T0104 («найдено ли разложение для каждого нечётного n<=99») выполнена полностью: accept закрыт, отказов нет. Для этого ограниченного утверждения проверка эквивалентна полному перебору: перебор конечен и исчерпан таблицей.

## Основание решения
emp без повышения: сдвиг этапа — воспроизведённый расширенный проверенный диапазон (валидный сдвиг по G6), но ось истины не меняется: нет письменного доказательства общей формы. Задача проверки T0104 считается закрытой CHK-вердиктом «подтверждено в формулировке задачи»; долг проверки по этой карточке погашен. Следующее расширение диапазона (n>99) — отдельная задача PLN, не повтор текущего счёта.
