## Утверждение
Для натуральных a<=b<=c<=d и целого k>=1 уравнение a+b+c+d = k·a·b·c·d имеет решения ровно: {(1,1,2,4)} при k=1, {(1,1,1,3)} при k=2, {(1,1,1,1)} при k=4; пусто при k=3 и при k>=5. С точностью до перестановки это полный список.

## Письменное доказательство
1. Граница произведения первых трёх: 4d >= a+b+c+d = k·abcd => k·abc <= 4. Отсюда при k>=5 решений нет (k·abc >= 5 > 4). Ветка k=3: abc <= 4/3 ⇒ только a=b=c=1, тогда d = 3/(3−1) = 3/2 не целое — пусто. Это закрывает пустоту k=3 и k>=5 без перебора.
2. При фиксированных (a,b,c) четвёртая переменная единственна: d = (a+b+c)/(k·abc − 1); условие d>=c даёт квадратичную границу на c при каждом (a,b) — ветвь конечна.
3. Разбор оставшихся случаев:
   - k=1: abc<=4 ⇒ (a,b,c) ∈ {(1,1,1),(1,1,2),(1,1,3),(1,1,4),(1,2,2)}. d=(a+b+c)/(abc−1): (1,1,1)→знаменатель 0; (1,1,2)→d=4 ⇒ {(1,1,2,4)}; (1,1,3)→d=5/2 нет; (1,1,4)→d=6/3=2 < c (перестановка того же кортежа); (1,2,2)→d=5/3 нет. Итог: одно семейство {(1,1,2,4)}.
   - k=2: 2abc<=4 ⇒ {(1,1,1),(1,1,2)}. (1,1,1)→d=3 ⇒ {(1,1,1,3)}; (1,1,2)→d=4/3 нет.
   - k=4: 4abc<=4 ⇒ только (1,1,1): d=3/3=1 ⇒ {(1,1,1,1)}. ∎
4. Контрпример к ожиданию PLN («пусто при k>=4»): (1,1,1,1) при k=4 — решение существует; подтверждён карточкой A0112 и этим доказательством (пункт 3, ветка k=4).

## Независимая сверка (воспроизводимость + усиленные сетки)

- Доказательная сетка a,b,c<=400 с точным выводом d (без границы на d): ровно те же пять ответов, 19.4 с (~1.3e8 проверок сокращённого цикла, под потолком по времени).
- Сокращённая доказательная область (пункты 1–2): идентичный результат за <0.01 с.
