# A0114 — Гипотеза Эрдёша–Страуса подтверждена спуском для всех нечётных n в 3..99: каждый 4/n разлагается в сумму трёх unit-дроби (первое решение сохранено в таблице, тождество проверено точно)

истина: emp (расширение проверенного диапазона метода спуска: все 49 нечётных n<=99 дали разложение; верификация тождества 4/n = 1/x+1/y+1/z построчно; отказов нет)
новизна: unc (классическая гипотеза, ожидается knw/cls по T0105 — но это не понижает ценность переиспользования метода %s4 в линии A0107-A0110-A0112)
метод: спуск %s4: x в [ceil(n/4), 3n/4], y в [ceil(nx/(4x−n)), 2nx/(4x−n)], z=nxy/((4x−n)y−nx) при целочисленности; первая найденная тройка останавливает поиск
доказательство: отсутствует — эмпирическое расширение диапазона; общий случай открыт (это и есть гипотеза Эрдёша–Страуса, A0108)
связи: A0108 (носитель метода), A0107, A0110
польза: active — калибрует спуск %s4 как рабочий инструмент линии; диапазон нечётных n<=99 закрыт без контрпримеров, следующий бот расширяет от границы 99, а не с нуля
артефакт: fixrealm/data/A0114-table.tsv
версия: QWR:ALV-1.0_PPV-1.0_TAV-1.0_b17

## Рецепт воспроизведения
python3 stdlib Fraction-free: цикл x,y с аналитическими границами, деление с остатком; <1e5 ops на всё; см. A0114-table.tsv; версия b17.
