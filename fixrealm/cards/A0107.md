# A0107 — Утверждённая форма обобщения a₁+…+aₙ=k·∏aᵢ есть ∏(k·aᵢ−1)=c≠1; при c=1 решений нет, параметр k не богатит (сводится к k=1 сечением по делителям)

истина: opn
новизна: unc
метод: посев направлений (оператор числовая аномалия из данных A0106 + перенос конструкции), сводится к трём дешёвым тестам ≤10^5
доказательство: отсутствует; карточка посева, повышение статуса запрещено до LIT/CHK. Попутно зафиксирован вывод: подстановка y_i=k·a_i даёт ∏(y_i−1)=c, где c∈{±1} только при исходном уравнении; для c=1 каждый множитель 1−1/x_i<1 при x_i≥2, значит произведение <1 — no-signal доказан элементарно (см. A0107-probe.tsv, строки c=1).

## Формулировка
Обобщение A0106 вида a₁+…+aₙ = k·a₁·…·aₙ через подстановку (%s5) эквивалентно ∏(k·aᵢ−1)=±1; правая часть никогда не бывает 1 в целых |aᵢ|≥1 нетривиально, а случай k=1 (единственный «богатый») переводит задачу в разложения единицы в египетские дроби — известную открытую область (конечность числа решений для фиксированного n не доказана).

## Направления (не более 3, каждое с дешёвым тестом)
D1 Контрпример нормализации: верно ли, что множество решений a+b=k·ab при k=1 и k=2 совпадает с точностью замены b→k·b, а при k∤2 пусто кроме (0,0)? Тест: расширить A0106 до k=1..8, B=200 (~1.3e5 сравнений). Ожидаемый сигнал: подтверждение (уже видно в probe: k=3..8 пусто). Вопрос новизны: cls (приём — вариант факторизации Саймона), проверить LIT.
D2 Дробный носитель: решения ∏(1−1/xᵢ)=c при c=1/2, 1/3 соответствуют египетским разложениям 1−…; растёт ли число решений с n быстрее экспоненты? Тест: таблица n=2..4, c∈{1/2,1/3}, B≤60 уже в probe (5→35 рост); WRK уточняет границы B по рекурсии Сильвестра ≤10^5. Вопрос новизны: knw требует ссылки (Sylvester sequence, Erdès–Straus).
D3 Вырожденный случай: класс решений с отрицательными aᵢ или нулями — замкнут ли он полностью (только (0,0))? Тест: B=200 со знаком, ~1.6e5 операций. Ожидаемый сигнал: закрытый тупик, фиксируется как отрицательный результат.

## Метод
Оператор выбора направления: числовая аномалия из данных (пустые столбцы k=1 и k≥3 в A0106-run.tsv) плюс перенос конструкции (подстановка ka−1 → египетские дроби). IDE не считает и не доказывает содержательные гипотезы; предварительная зонда-таблица сохранена как артефакт этапа. Декомпозицию и блоки номеров выдаёт PLN; вопросы скорректированы в inbox (замена Q1).
