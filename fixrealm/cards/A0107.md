# A0107 — Семейство sum=k·prod: спуск по последней переменной конечен; гипотеза: при n=3 решения ровно {(1,2,3) k=1, (1,1,2) k=2, (1,1,1) k=3}, при k≥4 только нулевые

доказательство: отсутствует; карточка посева. Зарисовка доказательства конечности спуска (не статус): для a₁≤…≤aₙ уравнение a₁+…+aₙ = k·a₁…aₙ даёт aₙ = (a₁+…+aₙ₋₁)/(k·P₂−1), где P₂ — сумма попарных произведений первых n−1; знаменатель растёт, ветвление конечно при фиксированных n,k

## Формулировка
Для натуральных a₁..aₙ и целого k≥1 пусть S=a₁+…+aₙ, P=a₁…aₙ. Утверждение: множество решений S = k·P конечно и вычислимо спуском; при n=3 непустые решения существуют только при k∈{1,2,3} и единственны с точностью до перестановки: (1,2,3), (1,1,2), (1,1,1).

## Тест (дешёвый, ≤1e5)
Спуск: цикл a,b ≤ 60, c=(a+b)/(kab−1) при kab−1 | a+b; сверка a+b+c == k·a·b·c. Стоимость 2.16e4 операций (зонд fixrealm/data/A0107-seed.tsv). Ожидаемый сигнал: список решений точно совпадает с гипотезой; любое решение при k≥4 или второе решение при каком-либо k — опровержение с контрпримером.

## Вопрос новизны
Египетские разложения единицы на 3 части и задача «sum divides product» — вероятная классика (OEIS A003862-подобные, Curtis 1976 для n=3?); LIT обязан дать два источника с датой, иначе unc остаётся.
