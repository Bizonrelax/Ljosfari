# A0110 — Сумма=произведение при n=3: a+b+c=k·abc в натуральных имеет ровно по одному семейству решений при k=1{(1,2,3)}, k=2{(1,1,2)}, k=3{(1,1,1)} и пусто при k=4..6 (с точностью до перестановки)

истина: emp (двойной метод: спуск по последней переменной c=(a+b)/(kab−1), B=60, k=1..6 + полный независимый brute-force 1<=a<=b<=c<=80; множества совпали побуквенно)
новизна: unc (не проверено LIT; задача T0105 в очереди; ожидаем knw/cls — частный случай egyptian sum=product, Curtis 1976)
метод: спуск (descent) с точной границей + brute-force сверка; исполнение задачи T0102 плана PLN
доказательство: отсутствует — emp; переход emp->prf требует письменного доказательства и закрытой CHK-задачи другим агентом. Кандидат доказательства: при k>=4 из kab−1 <= a+b для a,b>=2 следует конечность и пустота веток (проверить на CHK).
связи: A0107 (гипотеза-родитель, зонд seed), A0109 (нормализация k), A0106 (случай n=2)
польза: active — подтверждает нетривиальное ядро гипотезы A0107 и задаёт базис для индукции по n (A0112); отрицательная часть (пусто k>=4) закрывает ветку поиска контрпримеров при n=3 в диапазоне теста
артефакт: fixrealm/data/A0110-table.tsv
версия: QWR:ALV-1.0_PPV-1.0_TAV-1.0_b17

## Рецепт воспроизведения
python3 stdlib: rec(t,s,p): последняя x=s/(kp−1), целая при s%(kp−1)==0, x>=prev, x<=B; n=3,k=1..6,B=60 (~2.2e4 ops); brute-force кубический B=80 как контроль; см. A0110-table.tsv; версия b17.
