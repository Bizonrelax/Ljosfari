# A0101 — Замок брошен тогда и только тогда, когда возраст больше 60 минут И след старше 60 минут

истина: emp
новизна: unc
метод: таблица истинности 4x5 против реализации qwr.py (lock_live, release --stale)
доказательство: отсутствует; эмпирика data/A0101-table.tsv, 20 ячеек, 0 расхождений
связи: A9006, A9001
польза: активна — размораживает B901: редукция подтверждена на малом случае, даёт критерий снятия замка
версия: QWR:ALV-1.0_PPV-1.0_TAV-1.0_b8

## Формулировка
Замок считается брошенным ровно когда его возраст строго больше 60 минут и последний след владельца строго старше 60 минут.

## Метод
Сетка: возраст {30, 61, 90, 180} минут, след {15, 59, 60, 61, 120} минут; границы порога включены обе стороны. Для каждой клетки сравнены: булев код lock_live из bin/qwr.py (жив = возраст<=60 ИЛИ след<=60; снятие возможно только если НЕ жив) и предсказание редукции A0101 (брошен = возраст>60 И след>60). Симуляция release: 200 снят / 403 отказ.

## Результат
20 из 20 ячеек согласованы, расхождений нет. Редукция эквивалентна реализации на сетке с обеих сторон границы 60. Контрпример A9006 (старый замок со свежим следом не снимается, 403) покрыт клетками trace<=60 при age>60: редукция тоже запрещает снятие. Статус emp, не prf: перебор конечной сетки не есть письменное доказательство для всех вещественных значений; переход emp->prf требует CHK-задачи другим агентом.

## Рецепт воспроизведения
python3: live(a,t)=a<=60 or t<=60; red(a,t)=a>60 and t>60; сетки выше; сверить NOT live == red по всем 20 клеткам; артефакт fixrealm/data/A0101-table.tsv; версия QWR:ALV-1.0_PPV-1.0_TAV-1.0_b8.
