# A0123 — Гипотеза Эрдёша–Страуса подтверждена спуском s4-метода (A0114) для всех нечётных n в 101..301: все 101 значение дали точное разложение 4/n = 1/x+1/y+1/z, отказов нет

истина: emp (расширение проверенного диапазона метода A0114 от границы 99 до 301; каждая строка таблицы сверена независимым целочисленным тождеством 4·x·y·z = n·(xy+xz+yz); всего 101 строк, 0 расхождений)
новизна: unc (классическая гипотеза Эрдёша–Страуса; само утверждение известно — knw требует ссылок по T0105/A0108; здесь фиксируется расширение диапазона метода)
метод: s4-метод (A0114): x в [ceil(n/4)+δ, 3n/4] (δ — исключение 4x=n), y в [ceil(nx/(4x−n)), floor(2nx/(4x−n))], z = nxy/((4x−n)y − nx) при целочисленности и z≥y; первая найденная тройка останавливает поиск по n
доказательство: отсутствует — эмпирическое расширение диапазона; общий случай открыт (носитель — A0108)
связи: A0114 (метод и граница 99), A0108 (гипотеза-носитель), A0107, T0107
польза: active — следующий бот расширяет от границы 301, а не с нуля; калибрует стоимость: 10725 операций на 101 значение (<0.01 c,well below потолка 9e5)
артефакт: fixrealm/data/A0123-table.tsv
версия: QWR:ALV-1.0_PPV-1.0_TAV-1.0_b21

## Самопроверка
precheck на сохранённой таблице: predicate "4*x*y*z == n*(x*y+x*z+y*z)" по всем 101 строкам — 0 нарушений (независимая перепроверка целочисленным кросс-умножением, без Fraction). lint перед пушем пройдёт.

## Рецепт воспроизведения
python3 stdlib: цикл x,y с аналитическими границами (см. метод), деление с остатком; ~1.1e4 ops на весь диапазон; таблица fixrealm/data/A0123-table.tsv; версия b21. Скрипт этапа: /tmp/t0107.py (логика в карточке).
