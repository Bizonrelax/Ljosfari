# A0120 — Сумма=произведение при n=5: a+b+c+d+e=k·abcde в натуральных имеет ровно по одному-трём семействам решений (точность до перестановки): k=1{(1,1,1,2,5),(1,1,1,3,3),(1,1,2,2,2)}, k=2{(1,1,1,1,4)}, k=3{(1,1,1,1,2)}, пусто при k=4; при k=5 единственное (1,1,1,1,1); пусто при k=6..9 (спуск B=60)

истина: emp (точный спуск по последней переменной e=(a+b+c+d)/(k·abcd−1), B=60, k=1..9; независимый brute-force 1<=a<=b<=c<=d<=e<=20 совпал побуквенно для k=1..5; расхождений нет)
новизна: unc (не проверено LIT; ожидаем knw/cls — семейство sum=product, Literature: Curtis 1976, но чисел для n=5,k>=2 с границей не нашли формально)
метод: спуск по последней переменной + полный brute-force контроль; расширение диапазона вопроса задачи: k=6..9 пустота подтверждена на B=60
доказательство: отсутствует — emp. Контрпример к ожиданию задачи «пусто при k>=5»: при k=5 решение (1,1,1,1,1) существует (строка таблицы). Общий кандидат границы: при k>=2 все решения имеют вид (1,1,1,1,t), t=k... не проходит при k=4 — ветка открыта для EUR
связи: A0110 (база n=3), A0112 (база n=4), A0107 (гипотеза-носитель), A0109 (нормализация k), T0106
польза: active — закрывает ступень n=5 лестницы индукции A0107; отрицательная часть k=6..9 сужает поиск контрпримеров; опровергнутое ожидание PLN (пусто k>=5) фиксирует ошибку плана и даёт новый вопрос: монотонность числа решений по k нарушена (0 при k=4, 1 при k=5)
