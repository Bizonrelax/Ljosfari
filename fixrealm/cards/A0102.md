# A0102 — Граница порога строгая: ровно 60 минут живой замок не снимается

истина: emp
новизна: unc
метод: пограничные клетки таблицы A0101 (trace=60 при age=180; age=61 при trace=60)
доказательство: отсутствует; эмпирика data/A0101-table.tsv
связи: A0101
польза: активна — снимает неоднозначность "старше 60" в G4/mod-lock: строго больше, равенство живо
версия: QWR:ALV-1.0_PPV-1.0_TAV-1.0_b8

## Формулировка
Значение ровно 60 минут по обеим осям (возраст замка, возраст следа) трактуется как живое: условие брошенности требует строгого неравенства.

## Метод
Из сетки A0101 взяты пограничные клетки: (age=61, trace=60) -> отказ 403; (age=180, trace=60) -> отказ 403; (age=61, trace=61) -> снятие 200. Согласуются с кодом (<=60 значит свежий/молодой) и с редукцией.

## Рецепт воспроизведения
те же сетки, что A0101; проверить три названные клетки; версия QWR:ALV-1.0_PPV-1.0_TAV-1.0_b8.
