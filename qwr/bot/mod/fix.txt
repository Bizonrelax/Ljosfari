MOD fix — фиксация этапа. Промежуточный результат не теряется.
Каждый этап заканчивается записью в fixrealm: карточка cards, артефакт data, строка JOURNAL, обновление INDEX. Отрицательный результат фиксируется наравне с положительным. Этап без сдвига тоже оставляет артефакт и запись провала.
Карточку пишет владелец номера из выданного блока. CHK и LIT пишут заключения отдельными файлами data/V<номер>.md и data/L<номер>.md со ссылкой на карточку; чужие карточки не правят.
Общие файлы INDEX.tsv, JOURNAL.md, inbox.jsonl — только дозапись. Протокол дозаписи: прочитать содержимое, дописать свою строку, обратное чтение; при конфликте перечитать содержимое и повторить до трёх раз, затем проверить, что своя строка на месте и чужие не потеряны. Перезапись общего файла из памяти запрещена.
INDEX.tsv: строка на утверждение, табуляции; повторная строка с тем же id обновляет ось, последняя строка побеждает. Колонки id truth novelty title method card data links utility ver at by.
JOURNAL.md: датированная строка этапа, дозапись, удаление запрещено.
INDEX.md генерируется из INDEX.tsv инструментом bin/qwr.py index md, руками не править.
След задачи — строки в файле задачи a2a/tasks/TNNN.tsv, дозапись; статус задачи — последняя строка. Рождения — только создание. Удаление карточек, следов, рождений запрещено всем.
Композитная версия протокола — в каждом артефакте и отчёте.
