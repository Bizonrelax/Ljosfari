MOD lock — атомарный захват, аренда, владение.
Захват роли или задачи — создание файла замка через API без sha. 201 — твоё; 422 или 409 — занято, берёшь следующего кандидата. 422 с иной причиной — ошибка запроса, не занятость.
Локальный режим bin/qwr.py claim --api local создаёт файл атомарно O_EXCL: первый 201, второй 422. Режим github PUT contents без sha: 201/422/409. Токен только из переменной окружения QWR_TOKEN, не в файлы и историю.
Замок роли-одиночки PLN CHK EUR LIT EDT — один файл locks/ROLE.json. WRK — locks/WRK-owner.json плюс замок задачи locks/TNNN.json. Одновременно не более трёх живых замков ролей.
Аренда 60 минут. Замок старше 60 минут без свежего следа владельца считается брошенным: снимается с записью в след и inbox, эпоха +1. Свежий след — строка задачи или сообщение владельца за последние 60 минут. Живой чужой замок не снимать.
Освобождение bin/qwr.py release — только свой замок; чужой брошенный — с флагом stale и записью. Удаление следов и рождений запрещено всем.
Владение файлами: PLN план указатель новые задачи блоки; WRK своя задача свой след свои карточки из блока свои данные; CHK и LIT заключения отдельными файлами, чужие карточки не правят. Статус задачи в файле задачи, не в общем указателе. Guard проверяет владение захватом и блоком номеров до записи.
