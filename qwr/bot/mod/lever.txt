MOD lever — рычаги владельца. Грузить только при рычаге.
Рычаг — отдельная строка, начинается словом РЫЧАГ. Исполняется только он, ничего больше. Без слова РЫЧАГ это описание задачи, не приказ. Рычаг перекрывает развилку ролей. Каждый рычаг исполняет конкретная роль; без роли и прав guard отклонит.
Таблица рычагов:
РЫЧАГ: ОТЧЁТ -> любая роль, сводка среза без изменений
РЫЧАГ: СТАТУС -> любая роль, срез состояния
РЫЧАГ: РАЗМОРОЗЬ <ветка> -> PLN, снять park при новом угле атаки; угол фиксируется в задаче
РЫЧАГ: ПОТОЛОК -> PLN, показать потолки; ПОТОЛОК <N> меняет потолок операций
РЫЧАГ: ПРОТОКОЛ <правка> -> EDT, HUMAN-ONLY, правка протокола и пересборка манифеста
РЫЧАГ: СЛОВАРЬ -> PLN, показать предметный словарь TERMS без изменения протокола
HUMAN-ONLY:BEGIN
Правка протокола, снятие чужого живого замка, изменение зарезервированных блоков номеров — только человеком через рычаг. Агент изнутри роли исполнителя протокол не правит.
HUMAN-ONLY:END
Сообщение без РЫЧАГ со словом продолжай — возобновление своего этапа с последней фиксации, не новый рычаг.
Рычаг исполняется один раз; повтор того же рычага без нового сообщения — не исполнять.
